Privacy Policy

Ultimo aggiornamento: 13 Maggio 2026

Nota sulla Trasparenza: Questa applicazione è progettata per rispettare la tua privacy. Le immagini della pelle vengono elaborate esclusivamente in locale sul tuo dispositivo.

1. Raccolta Dati

L'app "Linee di Langer" accede alla fotocamera per analizzare le linee di tensione cutanea. Le foto scattate vengono salvate nella galleria privata del dispositivo dell'utente.

2. Elaborazione delle Immagini

Tutta l'analisi algoritmica avviene localmente. Nessuna immagine viene inviata a server esterni o terze parti senza il tuo esplicito consenso (es. backup su cloud se attivato dall'utente).

3. Servizi di Terze Parti

Se utilizzi le funzioni di notifica o autenticazione, l'app potrebbe utilizzare servizi come Firebase (Google). Ti invitiamo a consultare la loro policy per i dati di utilizzo minimi raccolti.

4. Diritti dell'Utente

Puoi eliminare i dati salvati e le immagini in qualsiasi momento direttamente dall'interfaccia dell'applicazione o cancellando l'app.
