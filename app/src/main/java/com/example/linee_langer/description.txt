3. Data Flow Diagram

This architecture ensures a Unidirectional Data Flow (UDF), which is the gold standard for Jetpack Compose.

- User Action: Clicks "Pick Image" in HomeScreen.

- Activity Result: System returns a Uri.

- ViewModel: Receives the Uri, triggers the LangerLineDetector.

- Logic Class: Processes pixels and returns a list of coordinates/lines.

- UI State: ViewModel updates a State object.

- Compose: HomeScreen sees the new state and draws the image with the Langer Lines overlaid on top.
